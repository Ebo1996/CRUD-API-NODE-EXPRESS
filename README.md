# 🛠️ Node.js REST API with Express and MongoDB

A simple CRUD API for managing products using **Node.js**, **Express**, and **MongoDB (Mongoose)**.

├── models/ 
│ └── product.model.js
├── routes/ 
├── server.js 
└── README.md


🚀 Getting Started

 1. Clone the Repository

git clone https://github.com/Ebo1996/simple-crud-API.git
cd simple-crud-API
2. Install Dependencies
npm install


3 Start the Server
To start the server normally:

node server.js
For development with automatic restarts using nodemon:
npx nodemon server.js
